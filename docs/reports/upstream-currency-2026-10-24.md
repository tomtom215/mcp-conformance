**What nobody covers, with demand evidence (not opinion):**

1. **Whole-spec clause accounting and honest "not observed".** The suite proves behaviour by driving scenarios and its own tracker shows the oracle gaps: conformance #546 (`server-initialize` passes a server that answers every method with a result), #515 (`tools-call-simple-text` passes when the tool does not exist), #516 (fails servers for capabilities they never declared), #451 ("Expose expected-vs-emitted check coverage per scenario"), #570 (two SEP-2243 server requirements untested), #552/#553 (a MUST graded as SHOULD). Already this project's niche; the new evidence is the open issues.
2. **An MCP Apps server validator.** ext-apps #673 (official validator, open since 2026-05-27, assigned), #674, #743, draft PR #722; the suite has no Apps scenario. Nobody ships one. Judgeable server slice is thin (section 2), so the real value is a static `ui://`/`_meta.ui` linter, not a trace judge.
3. **Resource-exhaustion and unbounded-state checks on MCP servers.** Two High unauthenticated DoS advisories in rmcp's HTTP server in four months (GHSA-9pj6 session table, GHSA-4432 tool-schema cache), plus the earlier DNS-rebinding one; the fuzzers that could probe this have tens of downloads a week. This is a live-probe tool (N junk tool names/sessions, assert flat memory), not an offline validator; the demand evidence is the advisories, not a request thread.
4. **Dual-era endpoints** (one server answering both handshake and 2026-07-28 clients). The spec's versioning page says a modern client against a legacy server "may even process an era-ambiguous method under legacy semantics"; C# 2.2.0 and Java 2.2.0-M1 ship hybrid/modern servers, Go 1.8.0 changes stateful-handler errors for 2026-07-28 requests; the suite states "Passing it on one wire says nothing about the other" and runs each wire separately. No tool judges one endpoint across both eras. Demand evidence is SDK release notes (inferred need, no issue asking for a tool).

Already covered, so not gaps: DNS rebinding (suite scenario `dns-rebinding-protection`), tool poisoning/prompt injection (snyk-agent-scan), live interactive debugging (Inspector, MCPJam), skills server conformance (suite alpha.12), tasks/triggers/URL-elicitation/DPoP/Server Cards (open suite PRs and issues: #374, #521, #541, #558, #523-#529, #550).
